# Mohammad Mehdi Asgari — Personal Website

Static professional website for GitHub Pages, covering aquaculture, fisheries, seafood processing, research, teaching, and professional experience.

## Files

- `index.html` — website content and structure
- `styles.css` — design and mobile layout
- `script.js` — mobile navigation and footer year
- `assets/` — favicon and downloadable CV PDFs
- `.nojekyll` — tells GitHub Pages to publish the files as a plain static site

## Publishing

For a personal GitHub Pages address, create a public repository named:

`YOUR-USERNAME.github.io`

Upload all files in this folder, then go to:

`Settings` → `Pages` → `Build and deployment` → `Source: Deploy from a branch` → `Branch: main` → `/(root)` → `Save`.
